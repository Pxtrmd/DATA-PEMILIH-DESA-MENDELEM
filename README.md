# Website Pencarian Data Pemilih

Website statis untuk mencari data berdasarkan nama.

## File
- `index.html` — halaman utama
- `style.css` — tampilan responsive
- `script.js` — logika pencarian
- `data.json` — data Nama, Dusun, RT, RW, TPS

## GitHub Pages
1. Buat repository GitHub baru.
2. Upload keempat file utama tersebut.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
6. Tunggu proses deployment selesai, kemudian buka URL GitHub Pages yang diberikan GitHub.

Website tidak membutuhkan PHP, Node.js, database, atau backend.
